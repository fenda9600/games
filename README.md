# 星际战车 · Planet Tanks

一款浏览器战车格斗小游戏：驾驶战车在 8 颗风格迥异的星球上与守卫一对一对决。

在线试玩：https://fenda9600.github.io/planet-tanks/

## 玩法
- 每场战斗地图中有两辆战车对决，击毁敌方战车后会爆出 🪙金币 和 💎钻石，靠近即可拾取
- 金币只能购买普通装备；钻石可购买高端装备
- 每次首次通关都会解锁新的星球和新的装备，通关全部星球后开启无尽深空模式
- 星球：地球、月球（低重力）、火星（沙尘暴）、冰霜星（打滑）、熔岩星（岩浆池）、毒雾星（视野受限）、水晶星（子弹反弹）、黑洞边缘（引力井）

## 操作
- WASD / 方向键：移动
- 鼠标瞄准，按住左键开火
- E / 空格：模块技能；Shift：冲刺（曲速引擎）；Esc：暂停
- 手机：左半屏摇杆移动，右半屏摇杆瞄准并开火

纯 HTML5 Canvas 单文件实现，无依赖，进度保存在浏览器 localStorage。
